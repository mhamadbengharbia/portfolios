MHAMED BEN GHARBIA — STATIC PORTFOLIO

This portfolio uses only:
- index.html
- style.css
- script.js

There is no React, Vite, npm install, package manager, or build command.

LOCAL PREVIEW
1. Extract the folder.
2. Open index.html in a modern browser.

For a local web server (optional), from this folder run:
  python -m http.server 8000
Then visit:
  http://localhost:8000

VERCEL DEPLOYMENT
1. Upload this folder to a GitHub repository or import the repository into Vercel.
2. Set the framework preset to "Other" (static site).
3. Leave the build command empty.
4. Set the output directory to the project root (or leave it at the default when importing this folder as the root).
5. Deploy.

Keep index.html, style.css and script.js in the same directory. Update the contact details and social links in index.html if they change.
